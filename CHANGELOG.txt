NFL-TCKR CHANGELOG
==================

0.1.23 — 2026-09-27
-------------------
- Logo / possession-icon white glow much more subtle: lower opacity (~half),
  tighter scale, smaller pad; team-name / text bloom unchanged from 0.1.22

0.1.22 — 2026-09-27
-------------------
- Team-name / text glow: real behind-glyph bloom (wide soft silhouette + heavy
  multi-pass blur at moderate opacity) so names keep normal weight instead of
  looking bold/outlined; shared _draw_text_glow also improves glow_all text

0.1.21 — 2026-09-27
-------------------
- AppBar fix: always ABM_NEW/QUERYPOS/SETPOS when docked (old “passive dock”
  skipped shell registration whenever anything was already at the top, so the
  bar never reserved desktop space)
- Force SPI_SETWORKAREA if the shell does not shrink the work area after SETPOS
- Deferred + retry AppBar setup after HWND is realized; clearer [AppBar] logs

0.1.20 — 2026-09-27
-------------------
- Glow reworked as soft background bloom (blurred halo behind content) instead of
  tight offset copies that only made glyphs look bolder

0.1.19 — 2026-09-27
-------------------
- Windows AppBar: docked mode reserves top desktop strip (SHAppBarMessage)
- Passive dock below sister tickers (MLB-TCKR / other *-TCKR) so bars don’t stack
- Fullscreen yield: hide via opacity when a fullscreen app owns the monitor
- Settings: “Docked (reserve desktop space)” checkbox (default on); undocked =
  floating always-on-top without AppBar

0.1.18 — 2026-09-27
-------------------
- Settings: optional "Glow team names" (team-color halo)
- Settings: optional "Glow all items" (text glow + faint white logo glow)

0.1.17 — 2026-09-27
-------------------
- Settings: Content transparency slider (scores/logos/names/stats strip)
- Renamed prior control to Background transparency for clarity

0.1.16 — 2026-09-27
-------------------
- Settings → General: Transparency slider (0% solid … 100% clear) for ticker
  background; persists as background_opacity

0.1.15 — 2026-09-27
-------------------
- Scroll debug default OFF; enable with `python NFL-TCKR.py --debug`
  (or NFL_TCKR_SCROLL_DEBUG=1; =0 forces off)

0.1.14 — 2026-09-27
-------------------
- Residual scroll judder: drive animation from DwmFlush VBlank (MLB _VBlankDriver),
  not QTimer — fixed dx still phase-drifted vs the display refresh
- Each VBlank: fixed px/refresh + synchronous repaint() before compositor deadline
- QTimer remains fallback if DwmFlush unavailable; SCROLL_DEBUG shows clock=VBlank|QTimer

0.1.13 — 2026-09-27
-------------------
- Scroll judder: fixed px/tick at ~display refresh (no wall-clock dt catch-up)
  — kills dx swing from 8 ms timer jitter (logs: spikes=0 but dx 0.2–5.3 px)
- Skip STRIP rebuild when slate fingerprint unchanged (scoreboard poll + QB rotate)
  — stops ~5 s / refresh 32k pixmap hitches when cards look identical
- Preserve scroll offset across rebuilds; SPIKE threshold 1.5× for softer cadence hits
- SCROLL_DEBUG summaries include fixed step=…px

0.1.12 — 2026-09-27
-------------------
- Fix name Y: center on *actual* KeepAspectRatio logo height (was using request box
  79px while logos draw at ~59px → names sat low beside logos)
- Extra optical lift (~logo_h/8); one-shot [CARD] align coordinate log
- Scroll debug default ON (SCROLL_DEBUG=True); NFL_TCKR_SCROLL_DEBUG=0 to silence
- All [SCROLL]/DEBUG] prints flush=True; loud startup "[SCROLL] profiler enabled"

0.1.11 — 2026-09-27
-------------------
- Card layout: team names optically centered on logos (QB stats still under name)
- Was centering name+QB as one block, which sat names too low beside the logo
  (incomplete: still used logo_size box, not pixmap height — fixed in 0.1.12)

0.1.10 — 2026-09-27
-------------------
- Scroll judder profiler: NFL_TCKR_SCROLL_DEBUG=1 (dedicated; API DEBUG can stay off)
- ~1s summaries: tick/paint dt min/avg/max/jitter/stdev, dx, offset, pause state
- Immediate SPIKE lines when tick dt > 2× timer target or paint interval > 2× VBlank
- Logs STRIP rebuilds (pixmap recompose hitch risk)

0.1.9 — 2026-09-27
------------------
- Smooth scroll: PreciseTimer ≤8 ms + delta-time px/ms (MLB QTimer path; kills ~1 Hz judder beat)
- Strip is a DPR-aware QPixmap; paint blits via QPointF (no per-frame rescale)
- SmoothPixmapTransform only at DPR<2; LED background cached
